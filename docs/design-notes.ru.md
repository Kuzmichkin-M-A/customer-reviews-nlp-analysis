# Проектные заметки v2

> Исторический документ: как версия 2 соотносится с планом доработок (исходный Excel-файл в репозиторий не входит) и какие ограничения приняты. Имена файлов здесь указаны до реорганизации проекта: `app_.py` → `app.py`, `data_util_.py` → `reviewlens/data_io.py`, `nlp_.py` → `reviewlens/nlp.py`.

Исходный файл требований: «правки_к_проекту.xlsx», листы «УКП», «Стандарт до конкурентов», «Факторный». Это план целевой версии на шесть месяцев, поэтому не все мероприятия являются задачами программирования. Приоритет — прямое указание пользователя: усилить учебный MVP без сложной архитектуры и API.

| Требование | Реализация в v2 | Граница реализации |
| --- | --- | --- |
| Импорт CSV/Excel, кодировка, разделитель, только текст обязателен | Сделано: CSV/XLSX, лист, предпросмотр, подсказки и ручное сопоставление | Вход должен быть таблицей с заголовком, не произвольным оформлением листа |
| Тональность по тексту, аспекты | Сделано: VADER EN, простой RU-словарь, фрагменты и ключевые слова | Локальный учебный baseline, не полноценная нейросетевая ABSA |
| Счётчик и 3–5 кликабельных цитат | До 5 цитат с кнопкой полного исходного отзыва и номером строки; если отзывов меньше, показаны имеющиеся | Внешняя ссылка только если присутствует в файле |
| Уверенность, смешанный/саркастичный отзыв | Mixed, маркеры возможной иронии, описание словарных сигналов | Вероятность правильности не имитируется; распознавание сарказма не гарантируется |
| «Вывод неверен» | Замечание к аспекту, CSV для ручного разбора | Без сервера и автоматического обучения |
| Проверка качества EN/RU и сравнение старого/нового | Воспроизводимый скрипт, 48 примеров общей тональности и 12 аспектных | Учебные составленные примеры; не независимая научная оценка |
| Переименовать, объединить, скрыть аспекты | Сделано, пересчёт статистики/сводки/периодов, JSON настроек | Редактируется семантика названия и группировки; словарь аспектов меняется в коде |
| Шаблоны отраслей | Общий, общепит, e-commerce, услуги | Предустановленные двуязычные словари |
| Русский и английский, интерфейс на двух языках | Сделано | Язык отдельного отзыва выбирается по алфавиту; смешанные тексты — ограничение |
| Мультиязычные модели, Sentence Transformers вместо TF-IDF | Опциональный локальный режим эмбеддингов и отдельная команда подготовки модели | Базовый TF-IDF оставлен для простого запуска; эмбеддинги не используются для тональности |
| Понятные названия тем и примеры | Наиболее частый аспект + ключевые слова, полные исходные отзывы | Названия эвристические; не LLM-резюме |
| Онбординг и сводка на первом экране | Шаблон, короткая инструкция, автоматически свернутый импорт после анализа | Показано до 3 проблем и 3 сильных сторон при наличии данных |
| История, сравнение периодов, дайджест, алерт | История сеанса, выбор двух периодов, экспорт дайджеста и флаг роста доли негатива | Нет фонового расписания, email/push и постоянного хранилища |
| Сравнение «я vs 3 конкурента» | До 4 групп по колонке филиала/компании/товара, аспекты и цитаты через общие фильтры | Данные загружает пользователь, сервис сам их не собирает |
| API площадок и партнёрства | Отложено по ограничению пользователя | Не требуются для учебного прототипа |
| Тарифы, оплата, пилоты, кейсы, публикации | Организационные мероприятия вне кода | Фиктивные тарифы/результаты пилотов не создавались |

## Спорные и неоднозначные моменты

1. **Описание MVP расходится с архивом.** README говорит об оценке тональности по рейтингу, но код `data_util_.py` уже вычисляет VADER и несовпадение звёзд с текстом. Сравнение качества выполнено именно с VADER исходного кода. В исходнике также встречаются f-строки, требующие Python 3.12, обязательные корпуса NLTK и multiprocessing при загрузке, усложняющие обычный запуск под Windows. В v2 эта зависимость от процессов и корпусов снята.
2. **Excel — целевое состояние, не список багов.** Срок шесть месяцев, цены и исследования конкурентов не доказывают доступность функций сейчас. Коммерческие заявления и оценки конкурентов не переносились в интерфейс как факты.
3. **Глубокие модели против простоты запуска.** Эмбеддинги выделены в необязательный режим. Обязательная загрузка модели на сотни мегабайт делала бы базовый запуск заметно сложнее.
4. **«Уверенность модели» и «сарказм» требуют отдельной валидации.** Для словарного алгоритма проценты уверенности не калиброваны. Вместо них показаны сигналы и явные ограничения.
5. **Мониторинг и история без сервера.** Реализован ручной локальный сценарий текущего сеанса; автоматические еженедельные рассылки и долговременная история требуют отдельной задачи.
6. **Реальные датасеты не размечены по тональности текста и аспектам.** Проверка на них подтверждает обработку и согласованность счётчиков. Она не измеряет точность интерпретации.
7. **«Любой формат файла» имеет предел.** Поддержаны табличные CSV и XLSX, но не XLS, сканы и листы со свободной вёрсткой. Приложение позволяет вручную выбрать нужные столбцы.
8. **Сравнение старой и новой кластеризации.** Без экспертных меток тем нельзя честно утверждать рост качества от эмбеддингов. В интерфейсе доступны оба режима и цитаты; результаты диагностического сравнения относятся к тональности, а не к качеству кластеров.

## Оформление интерфейса (ветка ui-style)

Только внешний вид, логика анализа не менялась; все 14 тестов проходят.

- Тёмная тема с оранжевым акцентом (`.streamlit/config.toml`), скрыта кнопка Deploy.
- `style.py`: цвета тональности для тёмного фона (Mixed — фиолетовый, чтобы не путать с акцентом), CSS-карточки метрик, единый стиль графиков Plotly.
- Главная страница до загрузки: заголовок, 4 карточки возможностей, блок «Как это работает», подсказка; в режиме отчёта — компактный заголовок.
- Графики: русские/английские подписи осей и легенды, подписи значений над столбцами, распределения по филиалам и локациям в два столбца.
- Человекочитаемая строка о кодировке и разделителе вместо словаря, плейсхолдер «Все» в фильтрах, инструкция в боковой панели — нумерованным списком, иконки у вкладок, облако слов в тёмной палитре.
